# OProject：经典 Django + Vue 2 管理系统模板

这是一个面向新手的前后端分离教学模板，包含登录、主界面、个人信息、头像编辑和基础角色权限。

> Django 5.0.7 和 Vue 2 已停止维护，本项目用于学习旧架构，不建议直接用于长期生产环境。

## 启动教程（两种方式完全分开）

请选择一种方式，不要同时执行：

- [一键配置与启动](docs/one-click.md)：推荐首次体验，只需运行一个脚本，但必须使用教程约定的数据库配置和前端 `8080` 端口。
- [手动配置与启动](docs/manual.md)：推荐需要自定义的用户，可自行设置数据库名、数据库账号、管理员账号及前后端端口。

| 对比项 | 一键方式 | 手动方式 |
|---|---|---|
| 适合场景 | 按默认配置快速运行 | 学习、开发和自定义配置 |
| 操作自由度 | 较低，请严格按照教程执行 | 较高，可按说明修改各项参数 |
| 前端端口 | 固定 `8080` | 可以自行指定 |
| 数据库 | 使用教程提供的默认名称和账号 | 可以自行创建和命名 |
| 管理员 | 自动创建固定教学账号 | 使用 `createsuperuser` 自行设置 |

## 首次运行后怎样再次启动

如果第一次已经成功运行，以后不需要重新创建虚拟环境、数据库或管理员：

- 一键方式：关闭原来的前后端窗口后，再次双击项目根目录的 `start.bat`。
- 手动方式：分别重新启动后端和前端，具体命令见[手动配置与启动](docs/manual.md#以后再次启动只需这两步)。

停止项目时，请在后端和前端两个终端中分别按 `Ctrl + C`。不要只关闭浏览器，关闭浏览器不会停止服务。

## 数据库参数

本地教学验证使用以下专用 MySQL 账号：

```text
数据库：oproject_db
用户：oproject_user
密码：OProject_Test_9vK4_r2L
主机：127.0.0.1
端口：3306
```

创建数据库后，将 `.env.example` 复制为 `.env`。完整 SQL 和操作顺序请查看上面的启动教程。

一键脚本将前端固定在 `http://127.0.0.1:8080/`。启动时会先检测并自动停止占用 `8080` 的旧进程；如果占用者是 IIS，会请求 Windows 管理员授权并只停止绑定该端口的 IIS 站点。后端默认使用 `8000`，被占用时可自动选择其他端口并由前端代理连接。
